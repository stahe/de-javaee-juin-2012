# Einführung in Java EE 5 / 6

👉 Online-Kurs:
[https://stahe.github.io/de-javaee-juin-2012/](https://stahe.github.io/de-javaee-juin-2012/)

## Überblick

Dieses Tutorial (Juni 2012) bietet eine praktische Einführung in **Java EE** anhand der Entwicklung einer **dreischichtigen** Anwendung:

* Überblick
* Geschäftslogik
* Datenzugriff

Das Dokument basiert auf Java EE 5 und 6 und verwendet **Maven-Projekte**.

## Behandelte Technologien

### Webanwendung

* JSF (Java Server Faces)
* EJB3 oder Spring (Geschäftsschicht)
* JPA (Hibernate / EclipseLink)

### Client/Server-Anwendung

* Swing (grafischer Client, Spring-Unterstützung)
* EJB3 oder Webservices (Server)

## Lernziele

* Die Architektur einer Java-Enterprise-Anwendung verstehen
* EJB3 und Spring vergleichen
* JPA für die Persistenz implementieren
* Eine vollständige Anwendung mit NetBeans erstellen

Das Dokument enthält Lösungsvorlagen und überlässt es dem Lernenden, bestimmte Abschnitte selbst zu vervollständigen.

## Voraussetzungen

* Kenntnisse der Programmiersprache Java
* NetBeans-IDE (empfohlen werden ca. 1 GB RAM)

## Weiterführende Literatur

* Java 5-Persistenz in der Praxis (JPA)
* Einführung in die Programmiersprache Java
* Einführung in JSF / PrimeFaces
